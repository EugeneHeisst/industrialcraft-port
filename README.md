# IndustrialCraft 2 PORT

Неофициальный порт **IndustrialCraft 2 Experimental 2.2.828** (Alblaka, Player, Thunderdark, RichardG, Chocohead и команда IC2) на **Minecraft 1.21.1 / NeoForge 21.1.256**. Версия **0.1.29**.

Реализованы энергосеть, кабели, генераторы, хранилища и трансформаторы; механизмы и переработка; жидкости, реакторы и взрывы; инструменты, броня и полёт; культуры, логистика, каучук и генерация руд, включая высокие горы. Есть русская и английская локализации, исходные ресурсы, GUI и необязательная интеграция JEI.

Последние исправления: запуск JEI без deadlock, стоимость инструмента по состоянию предмета для аддонов, общие теги ядерных материалов/охлаждающих капсул и добыча ножницами только при включённом режиме и полном заряде. Не объявляются дополнительные действия современных ножниц без реализации расхода EU.

В версии 0.1.24 восстановлено поглощение падения ботинками Nano/Quantum при частичном заряде и сильном ударе. Изменения энергии хранилищ и электрических механизмов помечаются для сохранения. Бутылировщик снова частично опустошает большие жидкостные контейнеры, сохраняя остаток и данные предмета; атомарные вёдра не опустошаются частично.

Версия 0.1.27 исправляет три визуальные ошибки: 77 значков механизмов показывают лицевую сторону, четыре варианта деревянных/железных лесов получают отдельные грани из исходной полосы текстур, а корпус лодки повёрнут вдоль направления игрока и движения. Исправление значков применяется только в GUI; размещённые механизмы сохраняют прежнюю ориентацию.

В JAR включены 14 новых текстур дроблёных и очищенных руд, переданных пользователем; генератор сохраняет их без изменений.

Версия 0.1.29 исправляет оплату Nano/Quantum только за принятый игрой урон (включая постоянный контакт с кактусом), возвращает исходный индикатор брони, устраняет дёргание нано-сабли при изменении EU. Исправлены объёмная модель буровой трубы, прозрачность стекловолоконного кабеля, иконка радиации, переводы генератора Стирлинга и загрузчика, подсказки текущих клавиш, урановый тег и лут сундуков по исходным весам IC2.

Для установки нужен **один** `industrialcraft2-modern-0.1.29.jar` в `mods/` и NeoForge для Minecraft 1.21.1. Все текстуры, модели, звуки, переводы, теги, рецепты и определения лута уже внутри JAR; отдельный ресурспак не требуется. JEI необязателен.

## Сборка и проверки

Нужна Java 21. `./build.sh clean` собирает `build/libs/industrialcraft2-modern-0.1.29.jar`; сборка автоматически архивирует JAR, SHA256 и результат проверки упаковки в `versions/<version>/`. `tools/audit_package.py <jar>` проверяет наличие ресурсов и замкнутость ссылок моделей, текстур и звуков. Для нестандартного расположения JEI используйте `-PjeiJar=/путь/к/jei.jar`; иначе сборка ищет локальный JAR и затем использует Maven.

Выделенный тестовый сервер: `JAVA_HOME=/usr/lib/jvm/java-21-openjdk JAVA_TOOL_OPTIONS=-Dic2.audit=server ./gradlew runServer -q`. Клиент: `./audit-client.sh -PwithJei=true`. Сетевой полёт: `./mp-flight-audit.sh`. Эти запуски используют отдельные тестовые миры; клиент скрыт и беззвучен.

Для версии0.1.24 прошли 388 серверных проверок, включая настоящий ServerPlayer.causeFallDamage и реальные жидкостные возможности предметов. Дополнительный native-аудит ASP проверяет сохранение EU в отдельных чанках. Результаты общей совместимости и предыдущих клиентских прогонов указаны в CODEX_HANDOFF.md.

Аддоны **Advanced Solar Panels PORT**, **Electro-Magic Tools PORT** и **Gravitation Suite PORT** выпускаются отдельными модами. Текущая точка продолжения и детали — [CODEX_HANDOFF.md](CODEX_HANDOFF.md).

Клиентский аудит 0.1.27 проверяет настоящие вершины трёх лодок при четырёх поворотах, 24 запечённые грани лесов и видимость передней грани пяти механизмов: 41/41. Галерея настоящих GUI-моделей: 25/25, включая 20 механизмов и четыре варианта лесов. Прошли также восемь страниц JEI и три игровых сценария лодок. Скриншоты и журнал находятся в `versions/0.1.27/`.

Новый набор IC2 0.1.27 / ASP 0.1.4 вместе с полным набором модов прошёл выделенный сервер совместимости 29/29 и скрытый клиент с JEI 14/14, без ERROR/FAIL. Журналы приложены к архиву этой версии.
