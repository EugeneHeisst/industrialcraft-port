# IndustrialCraft 2 PORT

Неофициальный порт **IndustrialCraft 2 Experimental 2.2.828** (Alblaka, Player, Thunderdark, RichardG, Chocohead и команда IC2) на **Minecraft 1.21.1 / NeoForge 21.1.256**. Версия **0.1.23**.

Реализованы энергосеть, кабели, генераторы, хранилища и трансформаторы; механизмы и переработка; жидкости, реакторы и взрывы; инструменты, броня и полёт; культуры, логистика, каучук и генерация руд, включая высокие горы. Есть русская и английская локализации, исходные ресурсы, GUI и необязательная интеграция JEI.

Последние исправления: запуск JEI без deadlock, стоимость инструмента по состоянию предмета для аддонов, общие теги ядерных материалов/охлаждающих капсул и добыча ножницами только при включённом режиме и полном заряде. Не объявляются дополнительные действия современных ножниц без реализации расхода EU.

## Сборка и проверки

Нужна Java 21. `./build.sh` собирает `build/libs/industrialcraft2-modern-0.1.23.jar`; архивы сборок и проверки находятся в `versions/<version>/`.

Выделенный тестовый сервер: `JAVA_HOME=/usr/lib/jvm/java-21-openjdk JAVA_TOOL_OPTIONS=-Dic2.audit=server ./gradlew runServer -q`. Клиент: `./audit-client.sh -PwithJei=true`. Сетевой полёт: `./mp-flight-audit.sh`. Эти запуски используют отдельные тестовые миры; клиент скрыт и беззвучен.

Проверено 363 серверных проверки отдельно и 371 с пилой Gravi Suit. Общий сервер с ASP, EMT, Gravi, Thaumcraft и остальным набором модов: 29 проверок; клиент с JEI: 14. Наличие проверок не заменяет проверку новых изменений в игре.

Аддоны **Advanced Solar Panels PORT**, **Electro-Magic Tools PORT** и **Gravitation Suite PORT** выпускаются отдельными модами. Текущая точка продолжения и детали — [CODEX_HANDOFF.md](CODEX_HANDOFF.md).
