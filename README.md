# IndustrialCraft 2 UNOFFICIAL PORT

Неофициальный порт **IndustrialCraft 2 Experimental 2.2.828** (Alblaka, Player, Thunderdark, RichardG, Chocohead и команда IC2) на **Minecraft 1.21.1 / NeoForge 21.1.256**. Версия **0.1.33**.

Реализованы энергосеть, кабели, генераторы, хранилища и трансформаторы; механизмы и переработка; жидкости, реакторы и взрывы; инструменты, броня и полёт; культуры, логистика, каучук и генерация руд, включая высокие горы. Есть русская и английская локализации, исходные ресурсы, GUI и необязательная интеграция JEI.

Последние исправления: запуск JEI без deadlock, стоимость инструмента по состоянию предмета для аддонов, общие теги ядерных материалов/охлаждающих капсул и добыча ножницами только при включённом режиме и полном заряде. Не объявляются дополнительные действия современных ножниц без реализации расхода EU.

В версии 0.1.24 восстановлено поглощение падения ботинками Nano/Quantum при частичном заряде и сильном ударе. Изменения энергии хранилищ и электрических механизмов помечаются для сохранения. Бутылировщик снова частично опустошает большие жидкостные контейнеры, сохраняя остаток и данные предмета; атомарные вёдра не опустошаются частично.

Версия 0.1.27 исправляет три визуальные ошибки: 77 значков механизмов показывают лицевую сторону, четыре варианта деревянных/железных лесов получают отдельные грани из исходной полосы текстур, а корпус лодки повёрнут вдоль направления игрока и движения. Исправление значков применяется только в GUI; размещённые механизмы сохраняют прежнюю ориентацию.

В JAR включены 14 новых текстур дроблёных и очищенных руд; генератор сохраняет их без изменений.

Версия 0.1.29 исправляет оплату Nano/Quantum только за принятый игрой урон (включая постоянный контакт с кактусом), возвращает исходный индикатор брони, устраняет дёргание нано-сабли при изменении EU. Исправлены объёмная модель буровой трубы, прозрачность стекловолоконного кабеля, иконка радиации, переводы генератора Стирлинга и загрузчика, подсказки текущих клавиш, урановый тег и лут сундуков по исходным весам IC2.

Для установки нужен **один** `industrialcraft2-modern-0.1.33.jar` в `mods/` и NeoForge для Minecraft 1.21.1. Все текстуры, модели, звуки, переводы, теги, рецепты и определения лута уже внутри JAR; отдельный ресурспак не требуется. JEI необязателен.

## Совместимость

**Sodium не поддерживается**, как и Iris, который работает поверх него. С ними возможны визуальные баги: неправильная отрисовка блоков, моделей, эффектов и интерфейса. Если что-то выглядит не так, сначала проверьте без Sodium и Iris и только потом сообщайте о баге.

## Сборка и проверки

Нужна Java 21: `./build.sh clean` создаёт `build/libs/industrialcraft2-modern-0.1.33.jar`. `tools/audit_package.py <jar>` проверяет наличие ресурсов и замкнутость ссылок моделей, текстур и звуков.

JEI берётся из Maven либо из `deps/jei-1.21.1-neoforge-19.57.0.451.jar`. Для другого пути используйте `JEI_JAR` или `-PjeiLocalJar`; прежний `-PjeiJar` также поддерживается. Явный Gradle property имеет приоритет над переменной окружения. При включении `-PwithJei=true` JEI также загружается в клиенте. Поиск зависимостей в установленных игровых профилях не выполняется.

Генерация ресурсов через `tools/gen.py` использует исходный IC2 в `related/ic2-reference/jar` и кэш текстур в `related/vanilla`. При отсутствии кэша укажите клиентские JAR через `MINECRAFT_CLIENT_JAR_1_7_10` и `MINECRAFT_CLIENT_JAR_1_21_1` либо положите их в `related/vanilla/minecraft-<версия>-client.jar`. Обычная сборка использует уже включённые сгенерированные ресурсы.

Выделенный тестовый сервер: `JAVA_HOME=/usr/lib/jvm/java-21-openjdk JAVA_TOOL_OPTIONS=-Dic2.audit=server ./gradlew runServer -q`. Клиент: `./audit-client.sh -PwithJei=true`. Сетевой полёт: `./mp-flight-audit.sh`. Эти запуски используют отдельные тестовые миры; клиент скрыт и беззвучен.

Для версии0.1.24 прошли 388 серверных проверок, включая настоящий ServerPlayer.causeFallDamage и реальные жидкостные возможности предметов. Дополнительный native-аудит ASP проверяет сохранение EU в отдельных чанках.

Аддоны **Advanced Solar Panels UNOFFICIAL PORT**, **Electro-Magic Tools UNOFFICIAL PORT** и **Gravitation Suite UNOFFICIAL PORT** выпускаются отдельными модами.

Клиентский аудит 0.1.27 проверяет настоящие вершины трёх лодок при четырёх поворотах, 24 запечённые грани лесов и видимость передней грани пяти механизмов: 41/41. Галерея настоящих GUI-моделей: 25/25, включая 20 механизмов и четыре варианта лесов. Прошли также восемь страниц JEI и три игровых сценария лодок.

Новый набор IC2 0.1.27 / ASP 0.1.4 вместе с полным набором модов прошёл выделенный сервер совместимости 29/29 и скрытый клиент с JEI 14/14, без ERROR/FAIL.
